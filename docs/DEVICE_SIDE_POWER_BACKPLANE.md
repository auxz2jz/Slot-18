# Device-side power backplane: 2 remote and up to 4 handheld cartridges

Date: 2026-10-07 America/Los_Angeles
**Status:** PROPOSED DESIGN ONLY; neither IP5328P pack module, charger, pogo dock, regulator, power MUX, solar input nor physical ESP32 hardware has been verified by user. No firmware/hardware modification authorized or performed. Do not claim test success.
Parent context: docs/USB_SOLAR_MULTIPACK_POWER_ARCHITECTURE.md and docs/18650_MULTICELL_POWER_SIZING.md.

## Decision scope
Distinct removable cartridge boards: each cartridge provisionally has a protected four-cell matched 1S4P 18650 assembly (nominal 3.6/3.7V) and candidate IP5328P USB-C PD power-bank charging/boost module. User intends a 5V cartridge power output through keyed/recessed dock contacts, removable standalone USB-C charging, in-device charge via wall/USB-C and optional solar input, and full-cartridge hot swap.

Device-side backplane must work for:
- remote: 2 cartridges;
- handheld: 2 initially, optional up to 4;
- no cartridges + qualified adequate wall/solar input when operating;
- any ONE installed cartridge whose output is rated for full peak system load;
- status/diagnostics for pack presence, source selection, USB/solar input and pack runtime estimates.

## Device-side functional blocks
1. **Per-cartridge slide-in receptacle** with keyed mechanically retained contacts: separate validated 5V BOOST OUTPUT and CHARGER INPUT power paths, common protected ground when supported, plus optional pack ID/gauge/temperature and enable/present. Pin count is NOT set until the exact IP5328P module pads/schematic and low-voltage contacts are inspected. DO NOT connect the booster 5V output and charger input together or assume both are independently available simply because USB-C is bidirectional. If board does not expose safe distinct charge-input pads and output pads, a practical USB-C charging connector/mating dock design or different power bank module may be necessary.
2. **Each slot:** current limiting / short-circuit fault isolation (eFuse), hot-plug inrush limit and reverse-current protection. Mechanical spring pogo contacts must be rated for peak current and cannot be accidentally shorted by metal. Provide a pack-present detection signal and, if appropriate, controllable shutdown/enable. Avoid discharge of all connected 5V boosters if load is near individual module rating; do not assume sharing equal currents.
3. **Cartridge output selection:** remote can evaluate a TPS2121 dual-input protected 5V power MUX (IN A, IN B -> protected 5V battery backup). TI TPS2121 has 2 inputs, reverse-current blocking, fast switchover, adjustable current limit to ~4.5A, rated path ~4A, and 2.7-22V operating range: https://www.ti.com/product/TPS2121 . For handheld, an engineer may evaluate one properly rated per-pack ideal-diode ORing stage per cartridge, or cascade 3 appropriately rated TPS2121 stages (A/B, C/D, combined winners). Cascading incurs voltage loss/heat and must be checked by calculation + actual bench test. Do not claim it automatically balances cartridge discharge; higher-voltage or priority source may supply the full load.
4. **External power:** device USB-C input (5V with correct sink CC, optionally 9/12/20V only after PD negotiation) -> input protection, limits and correctly rated 5V regulation -> 'external regulated 5V'. Optional solar PV input -> solar input regulator/MPPT or DPM -> same selected external 5V rail. NEVER put PV panel raw voltage on 5V system bus. Charger input budget prioritizes running the device; only surplus charges packs. Backflow to USB/solar must be blocked.
5. **System supply selector:** choose qualified external regulated 5V when present, fall back to cartridge 5V bus without reboot (another TPS2121 or appropriate priority power mux). External power should run display/remote directly *without relying on standard IP5328P charge passthrough*, because standard IP5328P designs disable boost output while charging. Source-loss re-enable delay of IP5328P boosters must be characterized: TPS2121's own 5µs typical switchover is NOT proof that the complete system survives delayed boost startup. If ALL installed cartridges stop supplying 5V while they charge, loss of USB/solar may cause a reboot. Mitigation may require dedicated always-ready battery path, a true power-path charger, qualified hold-up reservoir, one cartridge kept in discharge standby, or abandoning the IP5328P module for another charge/boost arrangement.
6. **Charge distribution:** after protected external input selection and power budgeting, each bay gets an independently isolated, current-limited/enable controlled **charging input** feeding that cartridge's IP5328P charger with correct USB-C input-role requirements. Charging path must not short a direct 5V booster output, cannot backfeed other cartridges, must not defeat USB PD CC handshake. If charging only via 5V pogo input rather than USB-C plug, validate that exact module accepts an independent regulated 5V input at its specified charging pads. IP5328P 'fast charge' is USB PD protocol on an appropriately wired USB-C port, not automatically achieved from power-only pogo pins. Device adapter power may be insufficient to charge all 2/4 packs fast while powering system; firmware-supervised charging can sequence packs, but hardware safety limits must persist through firmware reset.
7. **Power monitoring:** per-bay pack inserted, 5V output present, input/discharge current, charger active, expected pack ID (if implemented), pack voltage/SoC and temperature when proper gauge connected. IP5328P 4-LED level display does not establish measured aging/SoH; optional board I2C may not be brought out. If only 5V output measured, true 1S pack SoC cannot be estimated accurately; need a battery-side gauge/telemetry interface or accept 'unknown'. Aggregate charge/runtimes in Wh based on measured current and pack gauge, and last-seen/quality. Publish remote power status via sensor network for main screen, later Android/web.

## Candidate component comparison
- TI TPS2121: 2-input/1-output priority mux; good to EVALUATE for remote and external-vs-battery stage, not a charger: https://www.ti.com/product/TPS2121.
- TI LM66100: 1.5A ideal diode ONLY; **not** a general recommendation for a single high-load handheld pack unless measured path peaks remain below this limit with margin: https://www.ti.com/product/LM66100.
- IP5328P primary manufacturer datasheet: https://www.injoinic.com/api/static/uploads/20250528/20250528175417_6836dd49a604c.pdf . Standard design disables output when charging; specialized simultaneous-charge variant may still drop output during transition. Power-bank auto-standby when load small must be tested, especially at a low-power remote station.
- Waveshare 7in 5V USB power requirement: https://docs.waveshare.com/ESP32-S3-Touch-LCD-7 . Avoid backfeeding an attached programming PC USB cable when externally feeding the same power domain.

## Physical/bench safety gates
A. Measure screen/radars/ESP32 and future remote node average and peak load. Provisional engineering rail capacity goals only: remote 5V >=2A and handheld 5V >=3A, validate against chosen peripherals and actual thermal budget; these are NOT measured current values and current rating does not mean a load draws all of it.
B. With current-limited laboratory 5V power supplies (not unsupervised loose lithium cells), build TWO-input selector, test one alone, both present, unplug A/B at peak simulated load; measure rail undervoltage/recovery with oscilloscope.
C. Substitute a single candidate protected cartridge + IP5328P, confirm reliable 5V output startup, turn-off thresholds/low-current standby, selected 5V pads, maximum sustained current and module temperature.
D. Introduce direct external regulated 5V path and a separately enabled cartridge charger input. Observe boost output during charge and after external input loss, including real IP5328P reactivation delay. Design alternative supply hold-up if reboot is observed.
E. Test fast charge eligibility through USB-C PD role negotiation separately from 5V-only dock charge; per-contact current and heating; cannot assume PD passthrough on pogo contacts. Then simulate solar fluctuation with protected source.
F. Add 2nd cartridge, then optional 3rd/4th, validate no pack-to-pack reverse current or charger cross-feed, correct power-source telemetry, time-to-empty estimates, thermal limit, and fail-safe stop on short or incorrect insertion. Run guided test/diagnostic logs.
G. Use correct Li-ion matched-cell and 1S4P pack protection practice. Only full cartridges hot-swap; individual 18650 servicing is off-device and must not parallel cells with differing voltages or unknown condition.

**Do not buy multiple IP5328P boards, MUXes or pogo connector sets as 'compatible complete system' until a candidate hardware inspection and benchtop switchover test verifies the module's actual input/output interfaces and charge behavior.**
